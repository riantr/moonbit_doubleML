matrix: add whitebox tests for hot-path structural contracts

`matrix.mbt` is the most universally-called helper in the
library: every estimator uses `Matrix::from_array`,
`matmul`, `matvec`, `transpose`, `dot`, `mean`, `variance`.
The blackbox tests in `matrix_test.mbt` cover the public
surface (10 tests: from_array zero, identity, transpose
2x3, matmul identity, matmul known 2x2, matvec known, dot,
mean, variance, matvec_t kahan). This wbtest file covers
the structural contracts that the public surface relies on
but does not exercise directly:

  1. `matrix_ones_contents` — `Matrix::ones(3, 4)` produces
     a 3x4 matrix whose every entry is exactly 1.0. (No
     blackbox test asserted the actual contents of an
     `nrows x ncols` ones matrix.)

  2. `matrix_from_rows_2x3` — the row-list constructor takes
     `Array[Array[Double]]`, distinct from the flat
     `from_array(data, nrows, ncols)` constructor. Tests the
     `[1,2,3]` / `[4,5,6]` -> {1,2,3; 4,5,6} layout.

  3. `matrix_copy_is_deep` — the underlying `data` array
     must be a fresh allocation. The struct copy shorthand
     would alias it; `Matrix::copy` re-`make`s the array.
     Test by mutating `m1[0,0]` and asserting `m2[0,0]`
     is unchanged.

  4. `panic_matmul_dimension_mismatch_aborts` — the
     `require(a.ncols == b.nrows)` precondition (v0.48.0+
     cascade pattern) must abort on mismatch. Test name uses
     the `panic_*` convention so MoonBit's panic driver
     catches the abort message
     (`precondition failed at matrix.mbt:134:5-134:32`).

  5. `matrix_transpose_involutive` — the round-trip
     `T(T(M)) == M` is the structural identity that justifies
     the use of `transpose` in linear-regression plumbing
     (`X'X` / `X'y`). Single-transpose is covered by
     `matrix_transpose_2x3`; the round-trip was untested.

  6. `matmul_associativity_2x2x2` — `(A*B)*C == A*(B*C)`
     within 1e-9 relative tolerance. This is the
     compensated-summation invariant in `matmul`'s inner
     loop (per the v0.34.0+ kahan comment). Without
     compensation, naive matmul drifts at O(p * eps) and
     fails on adversarial inputs.

These tests are package-internal (the `panic_*` test in
particular relies on the abort-path code in `matmul`'s
`try { ... } catch { abort(...) }` wrapper, which is
package-private) and would not compile if moved to
`matrix_test.mbt`.
