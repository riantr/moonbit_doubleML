Release 0.27.0: DoubleMLLPLR partially logistic regression with Newton solve

New model: DoubleMLLPLR (upstream doubleml.plm.DoubleMLLPLR,
Liu, Zhang, Zhou 2021) for the partially logistic model
Y = expit(D * theta + r_0(X)) with binary Y. Two scores
("nuisance_space" default, "instrument" sample-weighted).

Load-bearing design points:
- Double cross-fit for ml_M / ml_a via the new public
  `double_cross_fit_predict` helper in kfold.mbt: outer folds
  partition the rows, inner folds re-split each outer fold's
  training slice for inner OOF predictions (used to build
  per-fold `W = logit(clip(M_inner, 1e-8, 1 - 1e-8))` and
  the per-fold preliminary `beta_f`).
- Newton solve for the nonlinear score, re-evaluating
  `psi(theta) = psi_hat * (y * exp(-theta * d) * d_tilde
  - (1 - y) * d_tilde * exp(r_hat))` at every step. The LPLR
  score is NOT linear in theta (it contains exp / expit),
  so the linear `newton_solve_score` does not apply. A
  *damped* Newton step (raw delta clipped to a 0.25-step
  sign-corrected descent when it would push theta outside
  [-5, 5]) is strictly more robust than the bare
  `scipy.optimize.root_scalar(method="newton")`, which fails
  to converge on this DGP.
- Variance at convergence via the linear-score trick:
  psi_a = psi_deriv(theta), psi_b = psi(theta) -
  theta * psi_deriv(theta); standard `var_est(psi_a, psi_b)`
  reused.
