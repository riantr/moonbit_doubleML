Release 0.26.0: DoubleMLPLPR static panel PLR with clustered inference

New model: DoubleMLPLPR (upstream doubleml.plm.DoubleMLPLPR,
Clarke & Polselli 2025) for static panel partially linear
regression, Y_it = D_it*theta0 + g(X_it) + alpha_i + zeta_it.
Four approaches: cre_general (Mundlak + post-hoc m_hat
adjustment), cre_normal ([X, d_mean] treatment regression),
fd_exact (first differences + lagged design), wg_approx
(within transformation). Both PO and IV-type scores.

Load-bearing design point: upstream re-wraps the transformed
panel as static-panel data with cluster_cols = id_col, so all
approaches take the CLUSTERED DML path:
- folds drawn over whole units (kfold on unique ids, expanded
  to row folds; no unit spans train+test),
- coefficient = fold-weighted ratio of cluster score sums
  (est_coef_cluster, w_k = 1/|I_k|),
- unit-level cluster-robust SE (var_est_cluster: gamma +=
  S_g^2/|I_k|, both accumulators / n_folds_per_cluster, scale
  1/(N_units*J^2)).
A naive row-level implementation reports se ~0.32-0.36 where
the clustered path reports ~0.02 and shifts coefs ~0.15 via
unit leakage in training folds. Cross-checked against installed
upstream doubleml 0.11.3 AND an independent hand-rolled numpy
cluster reference: all three agree on theta (~1.00) and se
(~0.02) across all four approaches.
