Release 0.33.0: fuzz cluster-vs-row SE ratio guard

Applies the v0.32.0 empirical lesson to the fuzz
infrastructure. Surface 9 (`DoubleMLPLR cluster-robust vs
row-level`) gains a new invariant: cluster SE / row SE
ratio stays within 1e4x of the larger value.

Background: v0.32.0's 30-seed empirical study on strong-IV
DGPs found that the cluster path is numerically fragile on
~10% of seeds — fold-weighted `J = mean(psi_a)` near zero
inflates the variance by orders of magnitude (one seed
hit cluster_se = 211049 while row_se was 90.5, ratio
2300x). The fuzz infrastructure before v0.33.0 only
checked cluster SE finiteness in isolation, with no
comparison to the row-level SE on the same DGP — meaning
a regression to "cluster path returns row-level SE" would
NOT be caught.

The new invariant `max(se_c, se_r) / min(se_c, se_r) < 1e4`
catches:
  - regression where the cluster SE diverges from the row
    SE by > 10000x (a pathological fold-split fingerprint);
  - accidental formula swap between cluster and row paths.

It does NOT catch:
  - sign flips in cluster-vs-row SE order (both
    arrangements are correct mathematical behaviour on
    different fold splits);
  - small (1.5-2x) disagreements within the empirical
    median ratio of 1.12x — a tighter bound would reject
    healthy fits on pathological seeds.
