Release 0.30.0: cluster-robust inference for DoubleMLPLIV / DoubleMLIIVM

Extends the v0.28.0 cluster-robust infrastructure to the
IV-family models. `DoubleMLPLIVData::new(x, y, d, z,
cluster_vars?)` and `DoubleMLIIVMData::new(x, y, d, z,
cluster_vars?)` accept a non-empty cluster vector; when set,
`fit()` routes through the clustered DML path:

  1. folds drawn over the unique unit ids, expanded to row
     folds via `expand_unit_folds_to_rows` (shared with PLR/IRM),
  2. causal parameter = fold-weighted ratio of cluster score
     sums (est_coef_cluster),
  3. unit-level cluster-robust SE (var_est_cluster).

All nuisances cross-fitted with cluster-respecting folds.
For IIVM the conditional `g0 / g1 / r0 / r1` cross-fits feed
their `cross_fit_iivm` helper directly (already accepts
`Array[Fold]`).

Dedup: extracted `cluster_causal_param_and_se` to kfold.mbt
to dedup the 13-15 line `psi_res` / `est_coef_cluster` /
`var_est_cluster` template shared by PLR, IRM, PLIV, IIVM.
Total duplication: 2 multi-line blocks (28 lines) -> 0 blocks.
Dupcheck: 0 over 33 production files.

API additions:
