PROBE: BLP confint_joint level, measured
================================================================================
BUG: blp_policy.mbt:746 had let z = 1.959963984540054 -- a hard-coded 95%
constant -- while level was accepted, range-checked (line 727) and then
IGNORED. level=0.5 and level=0.95 returned byte-identical intervals.

FIX: let z = norm_ppf((1.0 + level) / 2.0).
This is exactly the intended chi2(1 df) construction the adjacent comment
already described: chi2(1, p) = z_{(1+p)/2}^2, so the half-width multiplier is
sqrt(chi2(1,level)) = z_{(1+level)/2}, which is what
statsmodels.OLS.conf_int(joint=True) applies. norm_ppf is the same quantile
function the rest of the package uses for confint, and at level=0.95 it
reproduces the old constant, so the default path is unchanged.
