## Changes

- **`seed.mbt::seed_to_bytes` docstring**: the inline comment
  on the `match k % 4` block was rewritten from "REVIEW L6:
  `Int % Int` is signed, the wildcard covers the negative
  branch" (which was correct but no longer reflects why
  the wildcard is there) to a one-liner explaining that
  `k ∈ 0..32` and the `_` arm is dead at runtime, kept only
  to satisfy MoonBit's match-exhaustiveness check.
- **`_verify/` directory** dropped from ~250 files to 12
  files (the 6 most recent `T###-verdict.md` + `T###-commit-msg.txt`
  pairs; v0.4.0..v0.4.3 era historicals like H1/LOW/MEDIUM/
  REVIEW2/TODO-* were removed from the index but are still
  on disk for archival reference if anyone wants them).
  After this release, future verifier scratch files (build
  logs, probe outputs, Python validator outputs) will be
  git-ignored automatically.

## Notes / known limitations

- **`pkg.generated.mbti`** is git-ignored starting from this
  release. It is regenerated automatically by `moon info`.
  If you change the package surface and the CI reports
  "interface out of date", just run `moon info && moon test`.
- **`_verify/` cleanup is a one-way street for the historical
  files**. The 250+ removed files are still on disk for any
  checkout that pulled before this commit; if you want to
  drop them, `git clean -dfX _verify/` will keep the tracked
  `T###-verdict.md` / `T###-commit-msg.txt` files but drop
  everything else.
