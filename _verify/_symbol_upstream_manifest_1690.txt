# upstream doubleml 0.11.4 -- the symbols this repository cites

# WHAT THIS IS
# =============
# Every `doubleml.*` path named in this repository is a claim about the
# upstream package: it says that path resolves.  Round 50 found SEVEN of them
# that did not, and this file is the TRACKED record of what DOES resolve -- the
# anchor a check can consult in a fresh clone.
#
# The upstream package publishes a WHEEL, and its 0.11.4 sdist is a LOCAL CACHE
# (`_verify/doubleml-0.11.4.tar.gz`) that is not tracked.  So a contract run in
# a fresh clone cannot see it.  This file IS tracked, and it was EXTRACTED from
# that sdist; the sdist's sha256 is recorded below, so the snapshot can be
# tied to the artefact it came from.  Regenerate it with
# `_r50_gen_manifest_1650.py` and re-read the sha256 before trusting a change.
#
# WHAT IS CITED
# =============
# The library's own source comments (`moonbit_doubleML/**/*.mbt`), the six
# tutorials under `doc/`, the skill, the README, the ENGINEERING ledger and
# the CHANGELOG.  Two forms are NOT citations and are not listed: a GLOB
# (`doubleml.DoubleML*`, a family) and a PLACEHOLDER (`doubleml.DoubleMLXxx`,
# this repository's prose for "any upstream estimator").
#
# HOW A PATH RESOLVES (the model this file was built with)
# ========================================================
#   * a PACKAGE's namespace is what its `__init__.py` binds.  A
#     `from .mod import name` binds `name` in the package namespace and
#     SHADOWS the submodule `mod` of the same name -- so
#     `doubleml.utils.gain_statistics` is the FUNCTION, and
#     `doubleml.utils.gain_statistics.gain_statistics` does not resolve.
#   * a MODULE's namespace is its own top-level definitions.
#   * a CLASS's namespace includes the methods and properties it INHERITS.
#   * `doubleml/__init__.py` does not export `DoubleML`; the class lives in
#     `doubleml/double_ml.py`.
#   * a directory of .py files with no `__init__.py` is still a package (PEP
#     420); upstream ships `doubleml/did/utils/` that way.
#
# FORMAT
# =======
#   <cited path> <kind> <upstream file>:<line>
# one line per cited path, sorted.  `kind` is one of module / class / method /
# function / attribute / symbol.  The file:line is where the cited name is
# BOUND or DEFINED -- for a re-exported name it is the `__init__.py` line.
