Release 0.28.0: cluster-robust inference for DoubleMLPLR / DoubleMLIRM

Clustered-DML path for the two cross-sectional estimators,
wired through `DoubleMLData(cluster_vars=...)`. Mirrors the
upstream `DoubleMLData(cluster_cols=...)` API in 0.11.x.

When the data carries a non-empty cluster_vars vector, the
estimators route through:
  1. folds drawn over the unique unit ids (rows of one unit
     stay on the same side of every split),
  2. the causal parameter as the fold-weighted ratio of
     cluster score sums (`est_coef_cluster`, originally ported
     in v0.26.0 for DoubleMLPLPR),
  3. unit-level cluster-robust SE (`var_est_cluster`).

Per-row nuisances are cross-fitted with cluster-respecting
folds, so the per-row score elements are identical to the
row-level path — only the fold partition and the two
aggregation steps differ.

Dedup: the unit->row fold expansion logic was shared between
PLPR, PLR, and IRM as one 12-line block each. Extracted to
`expand_unit_folds_to_rows` + `build_row_unit_map` in
kfold.mbt; dupcheck now reports 0 blocks over 33 files.

API additions:
- `DoubleMLData` optional `cluster_vars` parameter
- `DoubleMLData::is_cluster_data` / `n_cluster_vars`
- `expand_unit_folds_to_rows` / `build_row_unit_map` in
  kfold.mbt
- `DoubleMLPLR::fit_cluster` / `DoubleMLIRM::fit_cluster`
  internal helpers (driven by `data.is_cluster_data()`)
