Release 0.12.0: Cleanup (chacha8_rng helper + verifier-scratch hygiene)

Added
- seed.mbt: chacha8_rng(seed) -> Rand convenience constructor.
  Replaces the 3-line boilerplate pattern
  (let bytes = seed_to_bytes(N); let rng =
  @random.Rand::chacha8(seed=Bytes::from_array(bytes)))
  in 13 test files and 5 demos with a single
  let rng = chacha8_rng(N).

Changed
- 13 test files + 5 demo main.mbt files switched to the new
  chacha8_rng helper (net -36 LOC of duplicated code).
- seed.mbt::seed_to_bytes docstring: rewritten the inline
  match-k%-4 comment from a historical L6 note to a
  one-liner explaining that k is in 0..32 (so the wildcard
  arm is dead at runtime, kept only for match-exhaustiveness).
- .gitignore: split _verify/ into tracked release artefacts
  (T###-verdict.md + T###-commit-msg.txt) and git-ignored
  verifier scratch (build logs, probe outputs, Python
  validator outputs, archived .mbt.archived files).
- pkg.generated.mbti is now git-ignored (regenerated by
  `moon info`); was previously committed by accident.
- README.mbt.md: refreshed source-file count (54 files =
  26 production + 28 test) and added a "Library helpers"
  section documenting chacha8_rng / stratified_kfold /
  PSProcessor for API-doc readers.

Tests
- 150/150 across native, wasm-gc, wasm, js (no test count
  delta; this is a pure cleanup release)
- 9/9 validate_*_with_python.py PASS
- All 5 demos (cmd/{main,datasets,did_binary,did_cs,did_multi})
  run cleanly with the new chacha8_rng helper and produce
  bit-equal output to v0.11.0

Cleanup
- _verify/ directory dropped from ~250 files to 12 files
  (6 T###-verdict.md + 6 T###-commit-msg.txt pairs from
  v0.7.0 through v0.11.0). Historical files (H1/LOW/
  MEDIUM/REVIEW2/TODO-*/final-*) were removed from the
  index but are still on disk for archival reference.
  Use `git clean -dfX _verify/` to drop them locally.

See _verify/T120-verdict.md.
