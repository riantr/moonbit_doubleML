## Notes / smells flagged but not addressed

- **QTE covariance (#2) and PQ/LPQ re-fit (#3)**: explicitly **out of scope** per the TODO #11a brief; tracked for TODO #11b.
- **LPQ `deriv` numerical issue**: the LPQ derivative `mean(score(theta + h)) - mean(score(theta - h))` is now scaled by the `sign` factor; the bisection has been verified to bracket on the canonical DGP. The 50-iter bisection remains (per TODO #11b, this is the PQ/LPQ re-fit candidate).
- **RDD delta-method uses unweighted residuals**: the cross-covariance `cov(raw, jump)` is the empirical `sum_k(res_y[k] * res_d[k]) / n_side^2` — matches the upstream `RDD` reference for the homoskedastic-OLS form (the same convention as the BLP Bug #5 fix). An HC0 (sandwich) variant would be a TODO #11c item.
- **`DoubleMLPolicyTree` depth recursion**: the `depth` field is accepted at construction and passed through to the struct, but the fit is still a single-level stump. The `require(depth >= 1)` precondition signals the documented limitation; the actual multi-level recursion is a TODO #11c item.
